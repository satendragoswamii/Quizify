“No questions found”
Ensure each question starts with a number (1., Q1., (1), etc.) followed by text. Leave a blank line between questions.
Wrong answers extracted
Use a clear answer line after options (e.g. Answer: B). Bold the correct option in DOCX for auto-detection.
File won’t upload
Check the file type is supported (.docx, .pdf, .txt, .md, .rtf, .html, .csv, .tsv, .xlsx, .json). Scanned PDFs contain no text — try copying the text and pasting it instead.
Export is empty or missing
Make sure your file or pasted text actually contains questions. If the issue persists, try the other input method.
